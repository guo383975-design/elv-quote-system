# 智能化弱电报价系统 · 后端依赖锁（Linux 已验证组合）
#
# 这份文件是 **pip freeze 的产物**，来自测试服务器上跑通过全部验收的那个 venv
# （Python 3.14 + PostgreSQL 18）。安装时优先用它，而不是 pyproject 里的 `>=` 区间 ——
# 区间会让不同时间、不同机器装出不同版本，出问题无法复现。
#
# 用法：
#     .venv/bin/pip install -r apps/api/requirements.lock.txt
#   deploy.sh 第 1 步与 deploy/remote_setup.sh 都会**优先**用这份锁；
#   文件不存在时才退回从 pyproject.toml 抽依赖（旧行为）。
#
# 两点注意：
#   1. **只在 Linux 上用**。里面含 httptools/uvloop 这类平台相关的轮子，Windows 开发机
#      请直接用 pyproject 的区间安装（Windows 上 uvicorn[standard] 不会装 uvloop）。
#   2. 故意不含 `passlib`：代码从 2026-09-30 起直接用 bcrypt
#      （passlib 1.7.4 与 bcrypt>=4.1 不兼容，会让后端初始化就失败，详见 app/core/security.py）。
#
# 更新方式（改依赖后）：
#     ssh 到服务器 → .venv/bin/pip freeze | sort > 新锁 → 提交
#   然后跑一次 deploy.sh 确认能装、能起、验活通过。
